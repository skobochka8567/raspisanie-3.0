# Расписание

Каждый день само заходит на сайт lk.asu.ru (расписание студентов АлтГУ),
берёт актуальные пары и присылает уведомление: пары на день, время выхода
из дома, погода и что взять с собой. Расписание руками вводить не нужно —
берётся с сайта в реальном времени.

По умолчанию — два уведомления: вечером (про завтра) и рано утром
(финальное напоминание про сегодняшний день).

## Как запустить

1. Загрузи все файлы из этой папки в репозиторий на GitHub (сохрани структуру).
2. Вкладка **Actions** — сборка запустится автоматически при пуше в `main`.
3. Когда сборка позеленеет → **Artifacts** → скачай `raspisanie-apk`.
4. Установи APK на телефон.
5. Открой приложение, разреши уведомления, нажми
   **"Включить ежедневные уведомления"**. На Android 12+ подтверди системную
   просьбу разрешить точные будильники.

## Настройки — `app/src/main/assets/config.json`

- `reminders` — список напоминаний (`hour`/`minute` — время, `days_ahead` —
  1 = про завтра, 0 = про сегодня)
- `travel_minutes`, `prep_minutes` — дорога и сборы в минутах
- `home_lat`, `home_lon` — координаты дома (для погоды)
- `exempt_subjects` — предметы с освобождением — помечаются "не идёшь"
  и не влияют на время выхода
- `always_bring` — что брать каждый раз, когда в этот день есть хоть одна пара
- `items_by_subject` — что брать под конкретный предмет
- `site_faculty_id`, `site_group_id` — твои айди на сайте расписания
  (сейчас: 15 и 2129441963 — из ссылки вида
  `asu.ru/timetable/students/15/2129441963/`). Меняются только если
  сменишь группу/факультет

Как достать свои айди заново (если понадобится): открой на сайте своё
расписание без входа в аккаунт (кнопка "поделиться" рядом с названием
группы в личном кабинете), в адресной строке будет
`.../students/ЧИСЛО1/ЧИСЛО2/` — это они и есть.

## Как это работает технически

Сайт грузит саму таблицу с парами отдельным запросом после открытия
страницы, с особым заголовком `X-CS-ID`. Приложение сначала обычным
образом открывает страницу за этот же день, вытаскивает текущее значение
этого заголовка, и повторяет запрос уже с ним — так же, как это делает
сам сайт в браузере. Если сайт когда-нибудь изменит эту механику,
уведомление придёт с текстом "не удалось загрузить расписание с сайта" —
это будет сигнал, что нужно поправить код.
